# Muhammadaziz Web Sayti — futuristik dizayn

## Ishga tushirish (Windows PowerShell)
1. ZIP arxivni chiqarib oling.
2. Loyiha papkasida terminal oching.
3. `py -m venv .venv`
4. `.venv\\Scripts\\Activate.ps1`
5. `pip install -r requirements.txt`
6. `python app.py`
7. Brauzerda `http://127.0.0.1:5000/` ni oching.

EduStar sahifasi: `http://127.0.0.1:5000/edustar`

## Yangilanishlar
- Asosiy sahifaga to'q ko'k/neon dizayn.
- Animatsiyali yulduz fon, hover nurlari va elementlarning ko'rinish animatsiyasi.
- Asosiy menyudan EduStar sahifasiga havola.
- Eski kurs/test/dars funksiyalarini saqlash uchun faqat taqdimot qatlami yangilandi.
